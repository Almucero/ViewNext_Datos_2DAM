# Documentacion de HiveFive2026

Este directorio centraliza la documentacion funcional y tecnica del estado actual del proyecto.

## Mapa de documentos

- `SETUP.md`
  - Requisitos, instalacion y arranque local completo.
- `ARCHITECTURE.md`
  - Vision general de arquitectura, capas y flujo end-to-end.
- `FRONTEND.md`
  - Frontend React/Vite, organizacion del codigo, i18n y pruebas.
- `BACKEND.md`
  - API Spring Boot, dominios funcionales y estrategia de testing.
- `DATABASE.md`
  - Modelo de datos, relaciones y convenciones de persistencia.
- `../bruno/HiveFive-API`
  - Coleccion Bruno para probar la API (`/api/v1`). Documentacion en **Overview** de la coleccion y en `README.md` de esa carpeta.
